# Online Pet Adoption Platform

## Project Overview
A Java-based Pet Adoption Platform that allows users to browse pets, register, log in, and submit adoption applications.

## Technologies Used
- Java
- HTML and CSS
- JDBC
- MySQL
- MySQL Connector/J

## Requirements
- JDK installed
- MySQL Server and MySQL Workbench
- Visual Studio Code or another Java IDE

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open MySQL Workbench and run the SQL script in the `database` folder.
4. Configure the database name, username, and password in `DBConnection.java` or the project's database configuration.
5. Ensure the MySQL Connector/J library is available.
6. Compile and run `Main.java` using the instructions provided for this project.
7. Open the local URL printed in the terminal, such as `http://localhost:8080`, if that is the configured port.

## Database Setup
Import the provided SQL script to create the required database and tables.

## Features
- User registration and login
- Browse available pets
- Shelter pet listings
- Adoption applications
- Admin management
